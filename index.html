Ratatouille API

Recipes, the chefs who wrote them, and the diet categories they belong to. Everything is sent and received as JSON.

Recipes

  • GET/recipes all recipes
  • GET/recipes/:id one recipe
  • POST/recipes add a recipe

Chefs

  • GET/users all chefs
  • POST/users add a chef

Categories

  • GET/categories all categories

Recipes

GET/recipes

Returns every recipe, newest first. Each recipe comes with its chef's name and its category name.

Response

[
    {
    "id": 1,
    "name": "Veggie Stir Fry",
    "ingredients": "broccoli, carrot, soy sauce",
    "instructions": "Fry the vegetables, then add the sauce.",
    "created_at": "2026-11-27T10:30:00.000Z",
    "chef_name": "Jeremy",
    "category_name": "Vegetarian"
    }
    ]

Status

  • 200 The list of recipes.
  • 500 Something went wrong on the server.

GET/recipes/:id

Returns one recipe. Replace :id with the recipe's number, for example /recipes/1.

Response

{
    "id": 1,
    "name": "Veggie Stir Fry",
    "ingredients": "broccoli, carrot, soy sauce",
    "instructions": "Fry the vegetables, then add the sauce.",
    "created_at": "2026-11-27T10:30:00.000Z",
    "chef_name": "Jeremy",
    "category_name": "Vegetarian"
    }

Status

  • 200 The recipe.
  • 400 The id is not a number.
  • 404 No recipe has that id.
  • 500 Something went wrong on the server.

POST/recipes

Adds a recipe. The chef is found by email: if that email already belongs to a chef, the recipe is added to them. If not, a new chef is created using chef_name.

category is the category's id number. Get the ids from GET /categories.

Request body

{
    "name": "Mushroom Soup",
    "chef_name": "Vegeta",
    "email": "vegeta@example.com",
    "ingredients": "mushroom, cream, salt",
    "instructions": "Boil everything for 20 minutes.",
    "category": 1
    }

Response

{
    "id": 7,
    "name": "Mushroom Soup",
    "ingredients": "mushroom, cream, salt",
    "instructions": "Boil everything for 20 minutes.",
    "created_at": "2026-11-27T11:00:00.000Z",
    "author": 2,
    "category": 1
    }

Status

  • 201 The recipe was added.
  • 400 A field is missing, the category is not a number, or the email has no @.
  • 409 That chef name is already used by a different email.
  • 500 Something went wrong on the server.

Chefs

GET/users

Returns every chef, including their email.

Response

[
    {
    "id": 1,
    "username": "Jeremy",
    "email": "jeremy@example.com"
    },
    {
    "id": 2,
    "username": "Vegeta",
    "email": "vegeta@example.com"
    }
    ]

Status

  • 200 The list of chefs.
  • 500 Something went wrong on the server.

POST/users

Adds a chef. Both the username and the email must be new. Usernames are not case sensitive, so "sam" and "Sam" count as the same name.

Request body

{
    "username": "Alex",
    "email": "alex@example.com"
    }

Response

{
    "id": 4,
    "username": "Alex"
    }

Status

  • 201 The chef was added.
  • 400 The username or email is missing.
  • 409 The username or the email is already taken.
  • 500 Something went wrong on the server.

Categories

GET/categories

Returns every category a recipe can belong to.

Response

[
    { "id": 1, "category": "Vegetarian" },
    { "id": 2, "category": "Vegan" },
    { "id": 3, "category": "Pescatarian" }
    ]

Status

  • 200 The list of categories.
  • 500 Something went wrong on the server.

Any other address returns 404 with { "error": "Route not found" }.
